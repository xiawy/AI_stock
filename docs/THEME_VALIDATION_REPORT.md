## 三、驳回（1 个）

### 家电（清洁电器）
```
- 成分股 8 只（603486 科沃斯 / 688169 石头科技 / 689009 九号公司 /
  603355 莱克电气 / 002705 新宝股份 / 603219 富佳股份 /
  603657 春光科技 / 605555 德昌股份）
- 单票权重 22% ≤ 40%          ✅
- 前二权重 44% ≤ 65%          ✅
- 主题内平均相关性 0.22 < 0.35  ❌
- 内部离散度 1.78 > 1.6        ❌
```

**原因**：这是第二次尝试（v1 是"家电（白电）"，三巨头 76%、相关 0.18）。
剔除白电后换成清洁电器整机 + 代工链，**仍然不成立**。整机票（科沃斯、石头、九号）
跟随的是"海外需求 + 新品周期"，代工厂（富佳、德昌、春光）跟随的是"客户排产 + 毛利"，
两者节奏并不同步 —— 这不是选股问题，是**这个细分确实没有统一驱动**。

**结论（口径纪律）**：家电行业内部没有能通过同涨同跌检验的 L3。
以旧换新等需求侧政策的影响**只落 L1 行业层面**，不进主题榜。
保留 `rejected` 记录而不删除，是为了让后来的人看到"我们试过两次，为什么放弃"。

同样是"强度 4 的利好"，落在这两类主题上的预期幅度理应不同 —— 这是统计锚的意义。

## 五、体检暴露的三个数据事实

1. **成分股清单会过期**：v1 查出 4 只已是 ST（南都电源/荃银高科/诺泰生物/易华录）。
   已剔除补位，但**清单必须季度刷新**，否则会被买入环节的 T9 过滤器挡住。
2. **闸门不能设理想值**：8~11 只的市值加权组合，前二权重 39%~62% 是常态。
   用 `CR5 ≤60%` 或 `前二 ≤55%` 都会误杀真实赛道（首轮 24/24 全灭）。
   最终口径：**单票 ≤40%、前二 ≤65%**，CR5 降为参考。
3. **离散度必须等权计算**：用市值加权算主题波动会虚高（电网逼近阈值），
   等权才纯粹反映相关性结构。
